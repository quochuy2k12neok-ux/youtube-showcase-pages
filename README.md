# 🚀 High-End YouTube Showcase Portfolio 2026

Dự án này là một bản Clone chuyên nghiệp của giao diện YouTube, được tối ưu hóa để trưng bày các sản phẩm lập trình cá nhân.

### 🌟 Tính năng nổi bật
- **Auto Video Preview:** Video tự động phát khi di chuột qua thumbnail.
- **Dynamic Category Filtering:** Lọc dự án theo công nghệ ngay tức thì.
- **Modern Tech Stack:** Sử dụng ES6 Modules, Flexbox/Grid và chuẩn Dark Mode.
- **Fully Responsive:** Hoạt động tốt trên mọi kích thước màn hình.

### 🛠 Cài đặt
1. Clone repo này về máy.
2. Mở bằng extension `Live Server` trên VS Code (Vì sử dụng ES6 Modules nên cần chạy qua server).
3. Truy cập vào `index.html`.
